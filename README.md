# Kronenkrieg – Die Reiche von Eldmar

Echtzeit-Strategiespiel für Android (Kotlin, offline, deutsch). Baue eine Wirtschaft auf, steige in neue Zeitalter auf und besiege die KI.

## Völker
- **Menschen** (Königreich Varnholm) – starke Gebäude, schnelles Bauen, Elite: Königsgarde
- **Elben** (Waldreich Sylvanthar) – Reichweite, Holz, Sicht, Elite: Sternenschütze
- **Orks** (Grakhul-Horde) – billige, schnell ausgebildete Armee, Elite: Berserker
- **Eisenbrut** (Feste Vorgrath) – zähes Fußvolk, Gold/Stein-Bonus, Elite: Schwarzschild

## Inhalt der ersten Version
- Zufallskarte mit Wäldern, Seen, Gold, Stein und Beeren
- 4 Rohstoffe, 9 Gebäude, 7 Einheitentypen je Volk, 3 Zeitalter
- Nebel des Krieges, Minikarte, Sammelpunkte, Türme
- KI-Gegner (1–3) in drei Schwierigkeitsstufen

## APK
Jeder Push auf `main` baut über GitHub Actions eine APK und veröffentlicht sie unter **Releases** als `Kronenkrieg.apk`.
